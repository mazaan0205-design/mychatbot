# Arena Strike // 5v5

A browser-based 5v5 tactical arena shooter prototype.

## Controls
- WASD — move
- Mouse — aim
- Left click — fire
- R — reload
- 1 / 2 — switch weapons

## Gameplay
Blue squad vs Red squad. Fight with AI teammates and enemies. First team to 25 eliminations wins.

Runs as a static site and is ready for Vercel.
